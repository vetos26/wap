# WAP Touch — Сайт-визитка на HTML5 и Bootstrap 5

Современный, сверхлёгкий сайт-визитка, спроектированный в концепции **WAP Touch** (сенсорный мобильный портал под управление одной рукой) с использованием **HTML5**, **Bootstrap 5.3** и **Bootstrap Icons**.

## Возможности
- **Touch-First интерфейс**: крупные сенсорные кнопки (`min-height: 48px`), тактильный отклик при нажатии, нижняя панель навигации под большой палец (`Thumb Dock`).
- **Адаптивная оболочка**: на смартфонах разворачивается на весь экран как нативное приложение, а на ПК отображается в компактной рамке `440px` с кнопкой переключения в широкий режим (`820px`).
- **Светлая и тёмная тема**: переключение `data-bs-theme` с сохранением выбора в `localStorage`.
- **Быстрые действия**: Email (`brehachev2026@gmail.com`), ссылки на MAX и VK, копирование почты в 1 касание с Toast-уведомлениями и кнопка «Поделиться».
- **Генерация vCard (`.vcf`)**: сохранение контакта прямо в телефонную книгу без сторонних библиотек.
- **Автономность**: Bootstrap 5.3.3 и Bootstrap Icons 1.11.3 подключены локально в `assets/vendor/`.

## Структура
- `index.html` — разметка визитки (вкладки «Визитка», «Услуги», «Проекты», «Связь» и модальное окно кейса).
- `assets/css/style.css` — современная стилизация WAP Touch, стеклянные панели, светлая и тёмная палитры.
- `assets/js/app.js` — переключение темы и ширины, живые часы, vCard-генератор, модальное окно проектов, валидация формы.
- `assets/vendor/` — локальные файлы Bootstrap 5 и Bootstrap Icons.

## Локальный запуск
```bash
python3 -m http.server 8080 --bind 0.0.0.0
```
Откройте `http://localhost:8080` в браузере (или проверьте в мобильном режиме DevTools).
